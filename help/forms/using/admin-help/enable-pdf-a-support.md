# PDF/A 지원 활성화 {#enable-pdf-a-support}

>[!NOTE]
> 
> 사용자에게 관리 콘솔에 액세스할 수 있는 관리자 권한이 있는지 확인하십시오.

PDF Generator는 Microsoft Excel, Microsoft PowerPoint, Microsoft Word 파일에서 PDF/A 호환 파일을 만드는 기능을 지원합니다.

1. 관리 콘솔에서 서비스 > PDF Generator > 파일 유형 설정을 클릭합니다.
1. 새로 만들기를 클릭하거나 기존 파일 유형 설정을 선택합니다.
1. Microsoft Excel, Microsoft PowerPoint 또는 Microsoft Word를 클릭한 후 PDF/A-1a 호환 파일 만들기를 선택하고 변경 사항을 저장합니다.
1. 기본 애플리케이션(예: Microsoft Word)에서 Adobe PDF > 변환 설정 변경을 클릭한 후 PDF/A-1b를 선택합니다.
